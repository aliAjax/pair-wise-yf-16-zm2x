# hxyfront-62004 滑雪板收板与交付核验台

源提示词编号：6

面向滑雪板调校店的「收板与交付核验台」：

- **收板登记**：固定器（品牌/编号）、安装孔位与位置角度、附件袋及随板附件逐项登记，记录客户确认方式（签字/拍照/签名/微信）、确认人与经办技师，生成收板核对快照。
- **维修变化**：维修中刃角、蜡型或底板修补发生变化时，先前核对快照自动作废并保留旧记录，工单退回「待复核」；技师按实物重新核对通过后生成复核快照，工单才可继续完工。
- **完工通知**：核对有效才能标记完工并通知取板。
- **取板核验**：固定器编号、孔位、附件数量逐项对照；全部对上且客户确认匹配才可交付；缺项/不符时留存「待取板」，生成缺项清单并保留历次核验尝试。
- **客户历史**：按客户展示每张工单的收板/复核（含作废）快照与交付快照。
- **数据**：全部保存在浏览器 `localStorage`（键 `ski-check-desk:v1`），不上传服务器，页面内可恢复演示数据。
